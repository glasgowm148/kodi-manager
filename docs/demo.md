# Find an add-on setting from your browser

[Watch the captioned demo](media/settings-demo.gif) · [Download the MP4](media/settings-demo.mp4) · [Download captions](media/settings-demo.srt)

The 45-second video is silent, with captions built in. It is an edited capture of the actual
dashboard against `scripts/demo_server.py`: synthetic data, view-only mode and no TV connection.
It demonstrates the browser dashboard; agent control is a separate setup option.

1. **Start with the dashboard.**
   - Open Kodi Manager in a browser on your phone or computer.
2. **Search across your add-ons.**
   - Enter a setting name in the search box. The demo uses `quality`.
   - The matching result names the add-on and shows the saved value.
3. **Open the matching add-on.**
   - Select **Open add-on**, then use **Find a setting** to narrow its list.
4. **Compare the saved value with its default.**
   - The synthetic example shows **Highest quality** saved as **1080p**, with a **4K** default.
   - Viewing a value does not change it. Changes need Write Mode and a separate review.

[Get started with the TV setup or guided agent prompt](../README.md#quick-start).
