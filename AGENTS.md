# Contributor instructions

Minimize tokens. Keep one canonical Python source and one canonical web asset tree.
Preserve loopback/read-only defaults, token auth, masked settings and reviewed layout version gates.
Use synthetic fixtures; never copy credentials, personal profiles/history, logs or vendor patch bundles.
Do not test mutations on a real TV without authorization and a known viewing state.
Run Python tests, focused lint, Node UI tests, library and deterministic add-on builds.
Update compatibility/docs when APIs change. The desktop installer and household patches are outside
this extraction; do not imply they are shipped.
