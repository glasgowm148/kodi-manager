Install using the TV remote

Add this source in Kodi → Settings → File manager → Add source:

https://glasgowm148.github.io/kodi-manager/
  1. In Kodi, enable Settings → System → Add-ons → Unknown sources.
  2. Open Add-ons → Install from zip file, choose that source and select repository.kodi-manager.zip.
  3. Choose Install from repository → Kodi Manager Repository (preview) → Services → Kodi Manager.
  4. In Configure → Dashboard, enable Allow LAN access and leave Enable writes off. Open Kodi Manager's tile under Video add-ons to display the dashboard address and private token.

Keep Kodi running. Open the displayed address on your phone or computer and sign in with that token. Updates follow Kodi's update settings. Full menu instructions and connection help.

The dashboard uses plain HTTP. Use a trusted LAN and keep the token private. This installs the public service, without household configurations or third-party patches.
