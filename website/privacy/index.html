Site privacy

This public documentation site has no analytics scripts, advertising pixels, forms, cookies set by our code or browser storage. Reading it does not connect to your TV.

It is hosted by GitHub Pages. GitHub may log visitors' IP addresses for security purposes; see GitHub Pages data collection and the GitHub privacy statement.

Links to GitHub, Agensi, Glama and other sites follow those sites' privacy practices. Do not send TV tokens, logs, personal profiles or backup files to this website.

This is separate from the installed software. Read the project's security guidance before connecting a TV or sharing diagnostic output.
