Kodi Manager vs Kore, Yatse and Chorus2: which Kodi tool do you need?

By glasgowm148, project maintainer · Reviewed 17 October 2026

Choose Kore or Yatse for an Android playback remote, Chorus2 for Kodi's browser media interface, and Kodi Manager for add-on settings, diagnostics and configuration recovery.

These tools can complement one another. This comparison is written by the Kodi Manager maintainer, based on the projects' own documentation. It is a scope comparison, not a performance benchmark.

ToolStart here when you want…Where it runs
KoreAn official remote, library browsing, playlist control, subtitles and audio-stream selection.Android phone or tablet.
YatseAn Android remote with voice commands and optional Pro streaming, casting and offline media features.Android phone or tablet; some features require its paid unlocker.
Chorus2Music, movie and TV-library browsing in a browser, playback control and many core Kodi settings.Kodi's web interface, enabled through Kodi's HTTP-control settings.
Kodi ManagerSearchable supported add-on settings, dependency information, playback-routing inspection and configuration checkpoints with restore/undo.A Kodi service with a separate browser dashboard; free MIT-licensed preview.

“I just want to pause a film or choose subtitles”

Start with a playback remote. Kore is Team Kodi's Android remote; Yatse adds its own remote and media features. Check each project's current feature list before choosing. Installing a maintenance service adds little value if navigation is your only goal.

“I want to use Kodi from a web browser”

First decide what you want to do in the browser. Chorus2 is the natural starting point for media-library browsing and playback. It also exposes many core Kodi settings, so browser settings access alone is not unique to Kodi Manager.

Choose Kodi Manager when the question is about an add-on's supported settings, the playback pipeline, diagnostic history or restoring a configuration checkpoint. It uses its own service address and token. Enabling Kodi's usual web interface does not install or authenticate Kodi Manager.

“I changed an add-on setting and need to undo it”

Kodi Manager keeps configuration backups for supported edits. Its dashboard has add-on backups, stack checkpoints and undo backups created before restores. Read the recovery workflow and limits before relying on it: these are configuration copies, not an Android-device image or cloud-history backup.

“Can an AI assistant help maintain the TV?”

The optional nvidia-MCP server exposes scoped tools to a compatible assistant on your computer. Neither a remote app nor a browser dashboard alone provides that local MCP connection. An ordinary browser chat cannot start the local server.

Check fit before installing

Kodi Manager is preview software targeting Kodi 19+; optional cached rows need Kodi 20+. Live evidence is limited to one customized Shield. General diagnostics are separate from the home-layout editor, whose write support is restricted to reviewed Bingie / Skin Shortcuts source versions and hashes.

Install the dashboard or walk through a supported settings change.
